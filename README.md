# Estudo de Caso: Geração de Front-End com React e ChatGPT - Projeto Final 

Este repositório contém o projeto final de um estudo dedicado a avaliar as capacidades, limitações e a qualidade do código gerado pelo **ChatGPT (GPT-4o)** na criação de uma aplicação front-end completa utilizando **React** e ecossistema moderno. 
Indo além de trechos simples de HTML e CSS, este estudo analisa o desempenho do ChatGPT em um ambiente moderno baseado em componentes. O objetivo foi construir uma aplicação React funcional, responsiva e com gerenciamento de estado, delegando à IA a tomada de decisões sobre arquitetura, composição de componentes, uso de hooks e estilização.

---

## Tecnologias & Ferramentas

* **Core:** React 18 / Vite (ou Next.js)
* **Estilização:** Tailwind CSS (ou Material UI / Styled Components)
* **Ícones:** Lucide React / React Icons
* **Motor de IA:** ChatGPT (GPT-4o)
* **Linguagem:** JavaScript (ES6+) / TypeScript

---

## Objetivos do Estudo - Disciplina: Desenvolvimento de Interfaces 

1. **Arquitetura de Componentes:** Analisar o quão bem o ChatGPT divide a interface em componentes reutilizáveis e modulares.
2. **Gerenciamento de Estado e Hooks:** Avaliar o uso correto de `useState`, `useEffect` e hooks customizados sem a criação de anti-patterns ou renderizações desnecessárias.
3. **Integração com Frameworks e Utilitários:** Medir a precisão da IA ao configurar e aplicar classes do Tailwind CSS ou componentes de bibliotecas UI.
4. **Refinamento de Prompts:** Documentar o processo iterativo de escrita de prompts necessário para levar o código de um rascunho básico até uma estrutura pronta para produção.
